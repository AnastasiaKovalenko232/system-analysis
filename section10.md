# Розділ 10. Проаналізувати систему безпеки

Для захисту даних користувачів та стабільної роботи SmartChef впроваджено наступні заходи безпеки:

1. Автентифікація та авторизація:
- Використання JWT (JSON Web Tokens) для керування сесіями.
- Паролі користувачів зберігаються виключно у захешованому вигляді за допомогою алгоритму bcrypt.

2. Захист передачі даних:
- Впровадження протоколу HTTPS (SSL/TLS) для шифрування трафіку між клієнтом (React) та сервером (Node.js).

3. Захист від поширених атак:
- Валідація та санація всіх вхідних даних для запобігання SQL-ін’єкціям та XSS-атакам.
- Налаштування CORS (Cross-Origin Resource Sharing) для обмеження доступу до API з неавторизованих доменів.

4. Резервне копіювання:
- Автоматичне щоденне резервне копіювання бази даних PostgreSQL на окреме хмарне сховище.
