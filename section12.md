# Розділ 12. Обрати методологію розробки

Для реалізації проєкту SmartChef обрано методологію **Agile (фреймворк Scrum)**.

Обґрунтування вибору:
1. Ітеративність: Можливість випускати функціонал частинами (наприклад, спочатку пошук рецептів, потім — особистий кабінет).
2. Адаптивність: Гнучка реакція на відгуки користувачів та можливість швидко змінювати пріоритети в розробці.
3. Командна робота: Чіткий розподіл ролей (Scrum Master, Product Owner, Developers) та регулярні зустрічі для синхронізації.

План спринтів (приклади):
- Спринт 1: Налаштування архітектури, бази даних та базового пошуку.
- Спринт 2: Реалізація системи реєстрації та кабінету користувача.
- Спринт 3: Інтеграція зі сторонніми API та створення списків покупок.
