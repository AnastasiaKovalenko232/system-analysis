# Розділ 5. User Stories у UML-нотації

Для візуалізації взаємодії користувача із системою побудовано діаграму послідовності (Sequence Diagram) для сценарію "Пошук та збереження рецепта".

Опис логіки:
1. Користувач відправляє запит на пошук до контролера.
2. Система звертається до бази даних рецептів.
3. Результати повертаються користувачу.
4. Користувач натискає "Зберегти", і система оновлює таблицю Favorites.
