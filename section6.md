# Розділ 6. Архітектура системи та залежності

Система SmartChef побудована за трирівневою архітектурною моделлю (3-tier architecture):

1. Рівень представлення (Presentation Layer):
- Реалізований на фреймворку React.
- Відповідає за відображення інтерфейсу, обробку кліків та валідацію форм на стороні клієнта.

2. Рівень бізнес-логіки (Application Layer):
- Побудований на Node.js (Express).
- Обробляє API-запити, реалізує алгоритми пошуку рецептів та керує автентифікацією користувачів.

3. Рівень даних (Data Layer):
- База даних (PostgreSQL або MongoDB) для зберігання інформації про користувачів, рецепти та списки обраного.

Залежності:
Система інтегрується з зовнішнім Spoonacular API для отримання актуальних даних про калорійність та склад страв.
