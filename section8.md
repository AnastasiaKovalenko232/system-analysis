# Розділ 8. Обґрунтування вибору типу бази даних

Для системи SmartChef обрано реляційну модель керування базами даних (RDBMS), а саме — **PostgreSQL**.

Обґрунтування вибору:
1. Структурованість даних: Рецепти, інгредієнти та профілі користувачів мають чітку структуру та зв'язки (1:N, M:N), які найкраще описуються SQL-таблицями.
2. Цілісність даних (ACID): Важливо забезпечити точність при збереженні улюблених рецептів та налаштувань користувача.
3. Потужний пошук: PostgreSQL має вбудовані можливості повнотекстового пошуку, що критично для пошуку страв за назвою або інгредієнтами.
4. Масштабованість: Система дозволяє легко додавати нові типи даних (наприклад, коментарі або рейтинги) без втрати продуктивності.

Альтернативно, для зберігання кешу або сесій користувачів може бути використано Redis (NoSQL) для прискорення доступу.
